  • October 27, 2026

    Editorial rule 8 (host questions inside answers) applied to Ep 002. Where the host asks a question, or makes a comment the guest's continuing answer responds to, in the middle of a guest answer, the guest's words are joined with an ellipsis, the host's words are shown with the answer word for word and attributed to the host, and the answer carries an 'Ellipsis added' tag and the Edited label (q6, q7, q17). Host crosstalk (any host remark that does not help the answer: an acknowledgement, an agreement, an echo or a side comment, of any length) is ignored: no ellipsis, not shown, no tag, no change to the label. Unmarked cuts in q13 and q15 are now marked with an ellipsis. Schema: the tag is a keyword on the answer's Clip and Quotation; each shown host question is its own Quotation by the host. Build: new host-join and host-question gates; every host run inside an answer must be declared either as a shown host question or as crosstalk (a non-rendered data-crosstalk attribute on the article, never for a run containing a question mark); the verbatim gate now sees host speech; the q13/q15 waivers are removed. The timing check now finds an answer's first words by the tightest match in the transcript before it considers the time the page claims, and a stale data-crosstalk entry, or an ellipsis that covers only crosstalk, fails the build. Ep 002 q9 passage 2 now starts at 20:13, where 'The human reader not.' is spoken (it had been marked 20:05); times only. No answer wording was changed.
